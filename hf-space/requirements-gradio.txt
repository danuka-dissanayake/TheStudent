# Gradio-SDK variant.

# Two rules learned the hard way on this Space:
#
# 1. Never pin a package the platform pins. On the Gradio SDK it pip-installs
#    torch, gradio[oauth]==5.15.0, uvicorn, websockets and spaces==0.51.3 on top
#    of this file; a second pin makes pip fail with ResolutionImpossible.
#
# 2. Never trust the prebuilt CPU wheel index here. It has served musl builds
#    ("libc.musl-x86_64.so.1: cannot open shared object file") to this glibc
#    container, which kills the app the moment it imports llama_cpp. Building
#    from source is a few minutes on a cached rebuild and is glibc-correct every
#    time — the compiler comes from packages.txt.
